# Assignment 1: Geospatial Analysis in R

## Overview

This assignment explores spatial data processing, geographic visualisation and predictive modelling using R. It covers three applications of geospatial analysis:

1. **Ottawa Starbucks Distribution:** Mapped Starbucks locations across municipal wards and calculated store concentrations relative to population.
2. **Zion National Park:** Combined hiking trail data from OpenStreetMap with elevation rasters to visualise trails and calculate elevation gain.
3. **Landslide Prediction:** Applied elastic net logistic regression and spatial cross-validation to investigate relationships between terrain characteristics and landslide occurrence.

## Skills Demonstrated

- Spatial joins and coordinate reference system transformations
- Vector and raster data processing
- Geographic data visualisation using `ggplot2`
- Integration of OpenStreetMap data
- Terrain and elevation analysis
- Elastic net modelling, hyperparameter tuning and spatial cross-validation
